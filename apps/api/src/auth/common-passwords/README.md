# Common-password list

Sign-up refuses a password on this list (ADR 0020, Addendum (1e-iii)). `isCommonPassword` in `../common-passwords.ts` is the only reader.

- Source: SecLists, `Passwords/Common-Credentials/10k-most-common.txt` (https://github.com/danielmiessler/SecLists), branch `master`.
- Licence: MIT, Copyright (c) 2018 Daniel Miessler. The notice is kept verbatim in `LICENSE` beside this file and must stay with the copy.
- ADR 0006 check (2026-11-20): it covered SecLists' MIT licence. Who first compiled the list is unconfirmed.
- Fetched: 2026-11-20.
- SHA-256 of the upstream file: `68782d6a4a19a4768d5f15dd66bd534e7a33055cc755411e33f16d18c50fdcce`. `common-passwords.spec.ts` rebuilds the file's bytes from the array (`entries.join('\n') + '\n'`) and pins this hash.
- 10,001 entries (not 10,000), all lower-case ASCII, no duplicate.
- Converted to a TypeScript array, entries unchanged: `common-passwords.data.ts` is written by a command, never by hand.

## Regenerate

From the repo root, with the upstream file at `<list>`:

```sh
node -e 'const fs=require("fs");const [list,licence,out]=process.argv.slice(1);const e=fs.readFileSync(list,"utf8").split("\n");if(e.pop()!=="")throw new Error("no final newline");const notice=fs.readFileSync(licence,"utf8").trimEnd().split("\n").map((l)=>(" * "+l).trimEnd()).join("\n");fs.writeFileSync(out,"/*!\n * SecLists Passwords/Common-Credentials/10k-most-common.txt: entries and order unchanged.\n * Generated by the command in README.md beside this file; never edit by hand.\n *\n"+notice+"\n */\n\nexport const COMMON_PASSWORDS: readonly string[] = "+JSON.stringify(e,null,2)+";\n")' <list> apps/api/src/auth/common-passwords/LICENSE apps/api/src/auth/common-passwords/common-passwords.data.ts
pnpm exec prettier --write apps/api/src/auth/common-passwords/common-passwords.data.ts
```

Prettier only changes the quotes and the trailing comma. The file starts with the `LICENSE` text as a `/*! ... */` comment followed by a blank line: TypeScript keeps such a comment under `removeComments`, so the notice travels with the compiled list in `dist` (`common-passwords.spec.ts` checks both). A new upstream version changes the hash: update it here, in the spec and in ADR 0020 in the same PR, after checking the licence again (ADR 0006).
