# OTA-139 slice 1f-iii-c: redirect ban, dynamic import gate, shared credential limits

Branch `feat/OTA-139-redirect-ban`. Lint, constants and one slug check; nothing new reachable.
- `no-restricted-syntax` (`apps/web/eslint.config.mjs`): value imports of `redirect`/`permanentRedirect` from `next/navigation` (every import form, re-exports, `next/navigation.js`) and anything from `next/dist/` banned app-wide; only a named import is freed in `src/auth/redirect-to.ts`, `src/anime/resolve-tab.ts`, `src/anime/season-redirect.ts`.
- Dynamic import gate, those three included: `import()` takes a string literal, never `next/navigation`, `next/dist/`, `…api/client` or a network module. `noInlineConfig` on every non-test file.
- `resolveTab` checks the canonical slug with `CANONICAL_SLUG_PATTERN` before its 308 (else the outage path).
- `IDENTIFIER_MAX` (254) and `PASSWORD_RAW_MAX` (1024) moved to `packages/shared-types/src/auth.ts`, used by the API DTOs and the web form; values unchanged.

Decisions: `default`, string-named and `next/navigation.js` imports banned too (next has no exports map); type-only imports allowed; ADR 0015 Addendum (1f-iii-c), pointer in ADR 0003.
Deferred: `NextResponse.redirect`/`Response.redirect` (1f-vi); client navigation, `createRequire`, path variants, aliased `apiClient`, `eslint-disable` in tests (not lintable); a shared `isAnimeSlugResolution` guard as `isExpectedBody` for `resolveAnimeSlug` and the slug proxy; `/sign-up` 308 (1f-v); rate-limit countdown and disabled button; frame-ancestors/X-Frame-Options before signed-in pages; Google button, forgot/resend links.
Accepted for beta (security M1/L6): sign-in has only the per-/64 limit and no sign-out; production sign-up is closed; /48 tier and sign-out (1f-iv) before sign-up opens.
Beta checks after merge (1f-iii-b): `/auth` form on beta, notice on a preview; `curl -sI 'https://beta.otakuleague.com/sign-in?next=/season'` → 308 keeping `next`; `WEB_PUBLIC_URL` equals the live origin; `pnpm dev` sign-in prints no action arguments.
