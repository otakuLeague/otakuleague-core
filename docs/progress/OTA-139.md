# OTA-139 slice 1f-iv-a: session core (`sessionCall`, `Viewer`, `loadViewer`, fault reports)

Branch `feat/OTA-139-viewer-sign-out`. Server code and lint only; nothing new reachable in the UI. Spec: ADR 0015 Addendum (1f-iv).
- `sessionCall` (`apps/web/src/auth/session-call.ts`): a `SessionToken`, GET or POST, key + Bearer, no `X-Client-Ip`, no body, `no-store`, one attempt; previews refused before any request, then `connection()` (throws in a cache scope). `readSessionToken` beside it is the only cookie reader. Lint gate is exactly `credential-call.ts` + `session-call.ts`; `createApiClient` banned for `api/client.*` too.
- `viewerFrom` (`viewer.ts`, pure) and `loadViewer` (`load-viewer.ts`, total): preview → `signed_out` before `WEB_PUBLIC_URL`; no/malformed cookie → 0 calls; else one `GET /me` at 2,000 ms; only a 401 `UNAUTHORIZED` envelope is `signed_out`; throws → `unstable_rethrow`, then `configuration` report and `unavailable`. Never writes a cookie.
- `reportAuthCallFault(route, fault)` + pure `authCallFaultOf` (`report-credential-refusal.ts`): one throttle per fault kind, tags and fixed fingerprint only, flushed in `after()`, never throws.
- `USERNAME_PATTERN` moved to `packages/shared-types/src/auth.ts` (value unchanged); new guard `isMeResponse`.

Decisions: `await connection()` before `WEB_PUBLIC_URL` is read (a prerender never bakes `unavailable` or reports at build); `viewerFrom` re-checks `isMeResponse`; a non-envelope 401 is `unavailable`, a non-envelope 5xx no fault (proxy page).
Deferred: iv-b (`signOutAction`, `redirectToSignedOut`, old-session delete, sign-in fault reports, loopback host check, rename the reporter file to `auth-reports.ts`); iv-c (header slot and sign-out button, root-layout re-render check on beta, `WEB_PUBLIC_URL` in `screenshots.yml`; ADR note on forged-cookie cost, L7, before iv-c). Review follow-ups: L3 lint row for `sessionTokenFrom` as the only brand maker; L5 API: a preview caller with a Bearer → 403, not 401; L6 `isExpectedBody` overloads; L8 the `credential_route` tag matches the redaction pattern (rename); `isMeResponse` vs imported usernames (OTA-149). From 1f-iii-c: `NextResponse.redirect` (1f-vi), `isAnimeSlugResolution`, `/sign-up` 308 (1f-v), rate-limit countdown, frame-ancestors before signed-in pages.
Accepted for beta (security M1/L6): sign-in has only the per-/64 limit and no sign-out; production sign-up is closed; /48 tier and sign-out (1f-iv) before sign-up opens.
Beta checks after merge (1f-iii-b): `/auth` form on beta, notice on a preview; `curl -sI 'https://beta.otakuleague.com/sign-in?next=/season'` → 308 keeping `next`; `WEB_PUBLIC_URL` equals the live origin; `pnpm dev` sign-in prints no action arguments.
