# OTA-139 slice 1a: accounts, sessions, GET /me (2026-11-14)
## What changed
- Migration `20261114120000_auth_sessions`: `app_user` and `auth_session` tables, with CHECK constraints on both.
- Pure session rules: 30-day idle expiry, renew when under 15 days left, 180-day hard stop.
- `SessionService`: raw-SQL lookup, verified users only, compare-and-set renewal.
- `SessionGuard`: web caller only. `open` gets 403 `INTERNAL_KEY_REQUIRED`; `preview` or a bad token gets 401 `UNAUTHORIZED`; DB down gets 503.
- `GET /me` returns `{ id, username }` with `Cache-Control: no-store`. `UNAUTHORIZED` code and `MeResponse` added to shared-types.
## Decisions
- OTA-139 split into slices 1a–1f: 1b PasswordHasher, `Random.bytes`, engines >=24.7; 1c sign-in/sign-out; 1d AuthToken/UsernameHold, sign-up, console EmailSender; 1e confirm + API runtime proof test; 1f web apiClient session/clientIp, ADR 0003 addendum, Server Action cookie.
- `usernameKey` column instead of citext. Tables named `app_user` and `auth_session`.
