# OTA-139 slice 1f-iv-a: session core (`sessionCall`, `Viewer`, `loadViewer`, fault reports)

Branch `feat/OTA-139-viewer-sign-out`. Server code and lint only; nothing new reachable in the UI. Spec: ADR 0015 Addendum (1f-iv).
- `sessionCall` (`apps/web/src/auth/session-call.ts`): a `SessionToken`, GET or POST, key + Bearer, no `X-Client-Ip`, no body, `no-store`, one attempt; previews refused before any request. `readSessionToken` beside it is the only cookie reader. Lint gate is exactly `credential-call.ts` + `session-call.ts`.
- `viewerFrom` (`viewer.ts`, pure) and `loadViewer` (`load-viewer.ts`, total): preview → `signed_out` before `WEB_PUBLIC_URL`; no/malformed cookie → 0 calls; else one `GET /me` at 2,000 ms; only a 401 envelope is `signed_out`; throws → `unstable_rethrow`, then `configuration` report and `unavailable`. Never writes a cookie.
- `reportAuthCallFault(route, fault)` + pure `authCallFaultOf` (`report-credential-refusal.ts`): one throttle per fault kind, tags and fixed fingerprint only, flushed in `after()`.
- `USERNAME_PATTERN` moved to `packages/shared-types/src/auth.ts` (value unchanged); new guard `isMeResponse`.

Decisions: `await connection()` before `WEB_PUBLIC_URL` is read, so a prerender never bakes `unavailable` nor reports at build; `viewerFrom` re-checks `isMeResponse` (total on its own); a non-envelope 401 is `unavailable`, a non-envelope 5xx is no fault (proxy page, ADR "5xx not reported").
Deferred to iv-b/iv-c: `signOutAction`, `redirectToSignedOut`, old-session delete after sign-in, sign-in fault reports, loopback host check (iv-b); header viewer slot and sign-out button, root-layout re-render check on beta (iv-c). Still deferred from 1f-iii-c: `NextResponse.redirect` (1f-vi), `isAnimeSlugResolution` guard, `/sign-up` 308 (1f-v), rate-limit countdown, frame-ancestors before signed-in pages.
Accepted for beta (security M1/L6): sign-in has only the per-/64 limit and no sign-out; production sign-up is closed; /48 tier and sign-out (1f-iv) before sign-up opens.
Next run: 1f-iv-b sign-out (`signOutAction`, `redirectToSignedOut` as a second helper in `redirect-to.ts`, old-session delete after sign-in through `sessionCall`, sign-in `reportAuthCallFault`, loopback host check).
