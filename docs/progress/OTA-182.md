# OTA-182: internal API key guard (autopilot, 2026-11-13)

## Slice 1 (API only, ADR 0019 proposed)
- Global `InternalKeyGuard` (`apps/api/src/common/internal-key.guard.ts`): `X-Internal-Api-Key` checked against `INTERNAL_API_KEY` or `INTERNAL_API_KEY_PREVIOUS` (SHA-256 + `timingSafeEqual`, all keys compared); 403 `INTERNAL_KEY_REQUIRED`; `@PublicRoute()` only on `GET /health`.
- Open while the key is unset (one production warning) so beta keeps deploying; env validation: 43–128 chars of `[A-Za-z0-9_-]`, empty = unset, `_PREVIOUS` alone = boot error.
- Tests pin both vars empty; one integration spec boots with a real env key. Runbook (enable, rotate, disable) in `docs/deploy.md`.
- Decisions: 403 not 401 (401 means "signed out", ADR 0015/0017); names reused from ADR 0015; no visitor-key header, the API derives it from `X-Client-Ip` (trusted only with the key).

## PR B (API only, ADR 0019 items 7-12, branch feat/OTA-182-visitor-import-limit, stacked on #84)
- `ApiCaller` (`apps/api/src/common/api-caller.ts`): `open` | `web` + branded `VisitorKey`; the guard records it in a WeakMap, `@Caller()` throws when none was recorded. `visitorKeyFromClientIp`: IPv4 as is, mapped IPv4 (dotted or hex) to IPv4, IPv6 to its /64 in one spelling, anything else (missing, list, zone id, brackets, port, padding, leading zeros, over 45 chars) `unknown`. Open mode never reads `X-Client-Ip`.
- `ImportLimits`: per-visitor buckets (5, one per 40 s), last-used order, lazy sweep on each granted take, cap 10,000; `refillBucket` is the one pure refill for both buckets; give-backs never exceed the burst.
- Importer: in-flight join free, visitor token before `shared()` (no await in between), global token inside; one `finally` gives tokens back when nothing was sent. Pre-send = `requestSent` false and a quiet or backoff reason (`refusedBeforeSending`): `fail()` in source-http and `UnusableAnswerError` leave `requestSent` false after a real request.
- 429s: `ANIME_IMPORT_VISITOR_LIMIT_REACHED` + `Retry-After` 1-40, `ANIME_IMPORT_LIMIT_REACHED` + `Retry-After: 20` (typed `retryAfterSeconds` on `ApiException`).
- Decisions: caller passed explicitly controller -> service -> importer (no AsyncLocalStorage); lazy eviction (no timer); a give-back is not a use (keeps order and `takenAt`); the reason constants live in `source.types.ts` and source-http uses them (exact match, the old `startsWith('cooling down')` had no other user).
- Review fixes: a `@PublicRoute()` handler records no caller in either mode; refusals before sending are no longer logged per import; the `unknown`-key warning has its own throttle; integration cases for a database failure first, AniList refused with Jikan asked, and a plain adapter error; Swagger and ADR wording on stored-but-unlinked anime, the /48 risk and the `X-Client-Ip` rollout gate.
- Local run: Prisma client generated with `PRISMA_SCHEMA_ENGINE_BINARY=/bin/true` (generation needs no engine), so unit tests, typecheck and lint ran; integration specs (new visitor tests in `anime.integration.spec.ts`) are CI-only here.
