# OTA-191: imported flag, slice 1 (autopilot, 2026-11-13)

Plan: architect, ADR 0018 (proposed). API + shared-types; no migration, no web behaviour change yet.

## Shipped
- `imported: boolean` on `AnimeListEntry` and `FranchiseEntry`: true only while an `anime` row is linked to the AniList id (same link as `AnimeService.findStored`), so a slug link costs no import token. One primary-key `IN` lookup (`findImportedAnilistIds`); manga always false.
- Web-trusted views (`AnimeListCard`, `AnimeFranchiseView`) take `imported?: boolean`; guards accept it absent, reject non-booleans, and now validate `related[].entries` too.

## Decisions
- Purged anime count as not imported (their slug page is a cold import again). OTA-192's `imported_at` must not redefine `imported`.
- A missing field stays tolerated for good: new web + old API falls back to nofollow id links.
