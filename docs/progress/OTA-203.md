# OTA-203: remove the @claude GitHub Action

- Deleted `.github/workflows/claude.yml`. Farouk doesn't use `@claude` / `claude-ok` on GitHub; the autopilot runs from the cloud scheduled task, not this workflow.
- Why: it ran main's setup scripts with a persisted write token on any commenter's `@claude`, before the action's own permission check.
- Docs: SETUP.md rows removed, ADR 0010 notes the removal.
- Farouk, after merge: delete the `CLAUDE_CODE_OAUTH_TOKEN` repo secret (Settings → Secrets → Actions). Dependabot PR #112 (claude-code-action bump) becomes moot; close it if Dependabot doesn't.
- Still open from the ticket: a `main` ruleset (require PR + CI) so no workflow token can push to main.
