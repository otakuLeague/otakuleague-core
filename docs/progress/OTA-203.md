# OTA-203: remove the @claude GitHub Action

This PR touches `.github/workflows/`, so Farouk merges it.

- Deleted `.github/workflows/claude.yml`. Farouk doesn't use `@claude` / `claude-ok` on GitHub; the autopilot runs from the cloud scheduled task, not this workflow.
- Why: on any commenter's `@claude` (public repo), it checked out main (issue comments) or the PR's merge commit (review comments) and ran its setup scripts with a persisted write token, before the action's own permission check. Run history shows it never executed.
- Docs: SETUP.md rows removed, ADR 0010 notes the removal.
- Farouk, now (before merge): disable the "Claude" workflow in the Actions tab; delete the `CLAUDE_CODE_OAUTH_TOKEN` repo secret and revoke that token at its source; delete the `claude-ok` label.
- After merge: close Dependabot PR #112 (only bumps this workflow). About 30 merged leftover branches still contain `claude.yml` and keep the review-comment trigger reachable through PRs between them; delete them.
- Follow-ups (not in this PR): a `main` ruleset (require PR + CI); `autopilot-merge.yml` should delete the head branch after merging; `docs/engineering-charter.md` still says required checks can't be enforced on a private free repo, but the repo is public.
