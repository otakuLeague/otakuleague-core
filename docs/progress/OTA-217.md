# OTA-217: trailer stops when the page is hidden or left

- **Cause:** `cacheComponents: true` makes Next 16 keep navigated-away routes mounted in `<Activity mode="hidden">` (`next/dist/client/components/layout-router.js`), so the trailer iframe kept playing.
- **Fix:** while playing, an effect's cleanup navigates the iframe to `about:blank` with `location.replace` (no history entry) and resets to the poster. Tests cover Activity hide/show, unmount and StrictMode.
- **Not verified:** a real browser check (play, go to Cast, sound stops, Back shows the poster).
