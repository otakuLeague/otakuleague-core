# OTA-196: per-visitor limit on anime search (OTA-189 slice C, autopilot, 2026-11-15)
## What changed
- `SearchLimits` (`apps/api/src/anime/search-limits.ts`): one `VisitorBuckets`, burst 20, one token back every 2 s, 10,000 entries max.
- `AnimeSearchService.search(request, caller)` charges the visitor first (after validation, so a 400 is free); refusal is 429 `ANIME_SEARCH_VISITOR_LIMIT_REACHED` with `Retry-After` 1-2. `open` callers are never charged.
- `sharedVisitorBucket(key)` in `common/api-caller.ts`, used by the search, list and import services.
- Unit + integration specs; ADR 0019 addendum; `.claude/rules/anime-data.md`, `api.md`.
## Decisions
- No global search bucket and no give-back; searches with no searchable text are still charged (ADR addendum).
- Reviews ran on Opus (Fable limit hit); builder was Sonnet.
