# OTA-207: throttle for Server Action POSTs

Spec: ADR 0015 Addendum (OTA-207). Web only: no API change, no new variable, dependency or error code.
- 207-a (#135, merged): `clientNetworkOf` in `api/client-ip.ts`; `createActionThrottleKeyer` (HMAC-SHA256) and `createActionThrottle` (fixed window, 60 per 60 s, 10,000 entries) in `auth/action-throttle.ts`.
- 207-b (this branch): `isPossibleActionPost` and `isCrossSitePost` in `auth/action-post.ts`, with a parity test against Next's `server-action-request-meta`. `auth/action-throttle-guard.ts` is wired in `proxy.ts` (matchers on the `next-action` header and `content-type`).
- Order: cross-site 403 before counting; then the /64 tier (IPv4 or IPv6 /64, HMAC, per-instance random 32-byte key) at 60 per 60 s; then the /48 tier at 300 per 60 s through a non-counting `peek`, so a POST counts on both tiers or on neither.
- Refusal: 429 `text/plain`, `no-store`, `Retry-After`, `ACTION_THROTTLED_TEXT`. `forgetEnded()` runs every pass. No IP: uncounted pass plus a tags-only report (`reportClientIpUnknown`, which never throws). `take` ends a key at its own window end after a clock step back. `clientSiteOf` added to `client-ip.ts`. Rules in `.claude/rules/web.md`.
- Checks: lint, typecheck, 2582 unit tests green.
- Verified in `next dev` (reviewer): 60 POSTs pass, the 61st gets 429; a foreign Origin gets 403 and is not counted; a spoofed `X-Forwarded-For` is ignored off Vercel.
- Not verified: `next build` (blocked by Google Fonts and the known `SeasonResultsView` export on main), Vercel `has` matchers, Sentry in the proxy function on Vercel.
