# OTA-137 Browse list pages: slice 1 (shared list template + /season)

- What changed (web only, no API or shared-types change): `/season` (`app/season/page.tsx`) with h1 "Fall 2026 anime", previous/next season links and "This season"; results stream behind `Suspense key={season-year}` with a head placeholder in the loading fallback. Shared template in `src/browse/`: `season.ts` (UTC quarters like the API, URL parsing with fallback to the current season, ASCII-only aliases, stepping Winter 1917..Fall of next year), `anime-grid.ts` (`collectGridPages` walks the API cursors, 48 per call, dedupe, `?page=` 1..10), `anime-grid-view.tsx` (loaded / end / capped / more failed / empty / failed, skeleton), `anime-card.tsx` (moved from the home row). `loadAnimeListPage()` in `src/anime/data.ts`; `loadAnimeList()` now calls it.
- Decisions: bad or partial `season`/`year` show the current season (no 404, no redirect); old-site params (sort, q, formats) ignored; "Show more" is a plain `Link` to `?page=n+1` (`scroll={false}`, no prefetch, nofollow) and re-walks the cursors server side. Walk bounded at ceil(pages/2)+1 API calls (6 at page 10); a short page cannot loop. Retries are plain `<a rel="nofollow">` (full reload). Empty copy: past season "No anime listed for <season>", current or future "Nothing announced for <season> yet". `await connection()` before `new Date()`. Season picker form is slice 2.
- Interim controls (OTA-189 not shipped): `Disallow: /season?` in robots.txt; every card, stepper and "Show more" link `rel="nofollow"` and unprefetched; old seasons do not claim slugs, so their cards link `/anime/anilist/:id`.

- API gap: `GET /anime/lists/:kind` has no page parameter, sort, total or rank; the result count, sorts, Rankings ranks and filter chips need them (ADR 0016 follow-up).
