# OTA-136: Home page, slice 1 (autopilot, 2026-11-13)

Plan: architect, slice 1 of 4. Web and shared-types only; no API, no migration.

## Shipped
- `/`: static hero (h1 = LCP, sign-up/sign-in CTAs) and three rows (Trending = `airing`, This season = `seasonal`, Top rated = `top`), one uncached `Suspense` each, so `/` stays Partial Prerender. States loaded/empty/failed/skeleton in a fixed-height `.hm-row-slot` (no CLS); one failed row never breaks the page.
- `isAnimeListPage` guards a card-shaped `AnimeListCardPage` (≤ 50 entries, positive ids, canonical slugs); covers render only for `https:` URLs. `CANONICAL_SLUG_PATTERN` moved to shared-types.
- Health status removed from home (`HealthStatus`, `getHealth`); ADR 0003 and docs updated.

## Decisions
- Every card link is `prefetch={false}` and `rel="nofollow"`: slugs are claimed for never-imported anime (OTA-190), so a followed link costs an import. Revisit with OTA-189/OTA-191.
- Cards show cover and title only; failed rows say "reload" (no Retry island yet).
