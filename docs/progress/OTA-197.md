# OTA-197: forget visitor IPs on a timer (autopilot, 2026-11-15)
## What changed
- `VisitorBuckets.forgetIdle()` and `forgetIdleVisitors()` on `ImportLimits`, `ListFetchLimits`, `SearchLimits`.
- `VisitorSweepScheduler` (`apps/api/src/anime/visitor-sweep.scheduler.ts`): one unref'd 60 s interval sweeps all three; logs nothing.
- Worst case an IP stays in memory after the last granted request: import 260 s, list 120 s, search 100 s. A spec checks the 5-minute promise from the exported constants.
- ADR 0019 retention addendum; `docs/deploy.md` rollout gate; `.claude/rules/api.md` line; privacy page paragraph + retention bullet, `lastUpdated` 2026-11-15.
## Decisions
- Scheduler lives in `anime/` (all limiters are AnimeModule providers); no timer inside `VisitorBuckets` (no lifecycle to clear it).
- Privacy text says "our server", not a blanket "never logged" (Vercel receives IPs, per the processors table).
