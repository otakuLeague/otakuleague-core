# OTA-192: imported_at marker for anime identities (autopilot, 2026-11-13)

## What changed
- Nullable `anime_identity.imported_at`, set once in `store()` when an identity first becomes an `anime` row; never cleared on purge.
- Migration with `lock_timeout` (5s, then RESET) and a two-step backfill: pre-OTA-190 cutoff 2026-11-13 06:01:15 UTC, then `GREATEST(anime.created_at, identity.created_at)`.
- ADR 0016 addendum: hand-run release runbook for never-imported list claims (SHARE lock on `anime_external_id`, re-mark, dry-run `SELECT FOR UPDATE`, deletes, ROLLBACK by default).
- ADR 0006 updated (AniList refusal steps); ADR 0007 addendum (never-imported slugs can be released).

## Decisions
- `imported_at` is never cleared, including on purge (keeps the ADR 0007 URL promise).
- Release path is docs-only (runbook), no script or endpoint: `scripts/` is protected and an endpoint adds attack surface.
- No index: the column is only read by the runbook.
