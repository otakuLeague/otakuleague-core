# OTA-190: Catalog lists claim slugs, slice 3 (autopilot, 2026-11-13)

Plan: ADR 0016, "Addendum: slice 3". API, shared-types comments and docs only; no migration, no web.

## Shipped
- `AnimeSlugClaimService.claimListed` runs in `fetchAndStore` after the page upsert (cold and background refresh): listed ids with no `anime_identity` get a canonical slug and romaji alias, one transaction each, in list order. Existing identities (removed included) are never touched. Never throws; P2002/P2034 retried 3 times; one warning per page (ids, error name/code).
- Shared ladder: `slugSource` and `pickCanonical` in `anime.slug.ts`, also used by the importer. Year outside 1900–2100 ignored. New reserved words: lists, slugs, season, top, genres, random.

## Decisions
- Claim scope until OTA-189: only non-genre lists that are non-seasonal or the current season (`claimsSlugs`). The cold request waits for claims (no source call, no bucket token).
