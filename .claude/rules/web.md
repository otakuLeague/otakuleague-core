# Web with the API (moved from CLAUDE.md)

- The web app copies its own variables (`WEB_ENV_VARIABLES` in `next.config.ts`) from the repo-root `.env`, inside the repo only; real env vars win. It needs `API_BASE_URL` (server-only, example value in `.env.example`; an older `.env` needs it added). A missing or invalid value fails the first API call with one message naming the variable.
- Restart `pnpm dev` after editing the root `.env`, and don't add `apps/web/.env*` files (ADR 0003).
- Anime pages (OTA-97): `/anime/[slug]` and its six tab routes (`/episodes`, `/cast`, `/music`, `/related`, `/stats`, `/community`). `apps/web/proxy.ts` (matcher `/anime/:path*`) calls `GET /anime/slugs/:slug/resolve` (300 ms timeout, answers cached about 60 s) and answers another slug or letter case with a 308 to the canonical slug on the same tab, and an unknown slug with the anime 404 page and a real 404 status. It has to be the proxy: with Partial Prefetching, Next sends a prerendered App Shell (status 200) before a page can resolve its slug. When the API is slow or down the proxy lets the request through and the page shows its own state. Check with `curl -I localhost:3000/anime/<alias>/cast`.
- Season selector (OTA-97): `season-selector.tsx` (client, disclosure of links, not a listbox) gets the main line trimmed by `seasonOptions()` in `src/anime/tabs.ts`; shown whenever the main line has 2+ seasons, hidden otherwise (one season, `unavailable` or a franchise failure, 2 s timeout). Every season is a link that keeps the tab (`seasonHref`, `prefetch={false}`); a season without a slug (not imported yet) links to `/anime/anilist/[id]/[[...tab]]` with `rel="nofollow"`.
- AniList id route (OTA-172): `app/anime/anilist/[id]/[[...tab]]` runs `seasonRedirect()` (`src/anime/season-redirect.ts`): validates id and tab (else 404 with no API call), calls `GET /anime/anilist/:id` (imports on first visit, 15 s timeout), then a 307 to the canonical slug on the same tab. API 404/400 or a null `canonicalSlug` → not found; an outage or timeout throws (error page). Not blocking: `loading.tsx` streams the anime page's `HeaderLoading`, so on a direct hit both outcomes are streamed, never a real 307/404 status: HTTP 200, then a meta refresh to the slug or the not-found UI. Client navigations from the selector just redirect. A slug that is not well formed throws (outage path). Always noindex: `robotsHeaders()` sends `X-Robots-Tag` on `/anime/anilist/:path*` even when indexing is allowed, and the slug proxy ignores these paths.
- Anime header (OTA-97): every value comes from `headerFacts()` (`apps/web/src/anime/header-facts.ts`), which hides what AniList lacks; add a header value there, with a test, not in the component. Accent text colours come from `accentPalette()`; a new chip colour goes in `tokens.css` (dark block and both light blocks) and in `CHIP_TOKENS` of `app/styles/tokens.test.ts`, which fails under 4.5:1. `next/image` runs with `images.unoptimized`: cover URLs from any source CDN render as-is, nothing is cached here.
- Overview tab (OTA-100, design `docs/design/overview-tab/`): `OverviewLoader` in `app/anime/[slug]/overview.tsx` reuses the request-cached `loadAnime()` (no extra API call) and renders nothing on failure or redirect (the header owns those states). Values come from `overviewFacts()` (`src/anime/overview-facts.ts`, built on `headerFacts()`); empty rows and an empty Details card are hidden. The synopsis is plain text rendered as React text (never `dangerouslySetInnerHTML`); the server decides if it collapses (>350 chars or >1 paragraph), and `synopsis.tsx` is the only client island (a `<noscript>` style un-collapses it without JS). Only an AniList synopsis is shown: MyAnimeList text waits on OTA-127 (ADR 0006). Slice 1: synopsis, details, genres (plain chips until browse routes exist).
- Motion and glass (OTA-150): transitions use the `--ease-*` / `--dur-*` tokens in `app/styles/tokens.css` (when to use each: `docs/design/system-v2/motion.md`), move things with `transform`/`opacity` only (colour and shadow transitions on small elements are fine), and each component states its `prefers-reduced-motion` behaviour. Frosted surfaces only through `.ol-glass` (solid fallback built in); never animate the blur.
- Global shell (OTA-152, design `docs/design/global-shell/`, ADR 0014): `app/layout.tsx` renders the static background (`.sh-bg`), `SiteHeader` and `SiteFooter` on every route; styles in `app/styles/shell.css`, `--brand-a/--brand-b` and `--header-h` in `tokens.css`. Header menus are native `<details name="sh-menu">` through `Disclosure` (`src/shell/disclosure.tsx`: React holds no open state, the enhancer only closes on Esc, outside pointer, focus leaving, link click); a list of links that opens in place is `<details>`, anything that traps focus or is an ARIA composite is Base UI. Nav links and active section by whole path segment in `src/shell/nav.ts` (`activeSection`); `HeaderNav` reads `usePathname` inside a `Suspense` whose fallback is `HeaderNavView pathname={null}`, so the root layout stays static. Search is a plain `GET /search?q=` form until OTA-98. `html, body` use `overflow-x: clip` (hidden breaks the sticky header); fixed bars sit at `top: var(--header-h)`. Below 1100 px (`--bp-lg`, media query 1099.98px) the header search box is hidden so the nav and guest actions fit; below 768 px the header shows logo + Sign in only until the mobile sheet slice. Menu panels are solid `--surface`, not `.ol-glass` (a backdrop-filter nested in the header's glass does not blur). Links to routes that don't exist yet use `prefetch={false}`; the account menu, sheet, 404/500 restyle and hiding the shell on `/auth*` and `/onboarding` are the next OTA-152 slices.
- Theme (`src/shell/theme.ts`): System / Light / Dark in the `ol-theme` cookie (System clears it). An inline script in `<head>` (`THEME_BOOT_SCRIPT`) sets `data-theme` on `<html>` before paint; the server does not read the cookie, which would make the root layout dynamic and lose Partial Prerendering (ADR 0003). `ThemeSwitch` reads the cookie through `useSyncExternalStore` (server snapshot System) and every instance stays in sync through the `ol-theme-change` event. Media queries use 767.98px for `--bp-md` (custom properties don't work in media queries).
- UI and motion libraries (ADR 0012): Base UI for every interactive primitive (dialogs, menus, tabs, select, tooltip, combobox), Motion for component animation, GSAP only for home/celebration showpieces via `next/dynamic`, Embla for carousels, Sonner for toasts, React `<ViewTransition>` as progressive enhancement. Add each in the first PR that needs it, with its license and gzipped size. Reduced motion turns animation off; transform/opacity only.
- Vendored skills in `.claude/skills/` (gsap-*, vercel-react-view-transitions, web-design-guidelines) are reference only: CLAUDE.md and ADR 0011/0012 override them (Motion is the default, GSAP only for showpieces, durations and easings from tokens.css, no new dependency without a stated reason).
- Search indexing (OTA-134): the beta is noindex through `SEARCH_INDEXING` in `apps/web/src/seo/indexing.ts` (root `metadata.robots`, plus an `X-Robots-Tag` header on all routes from `headers()` in `next.config.ts`; a test fails if another file under `app/` sets `robots`). `public/robots.txt` only has `Disallow: /anime/anilist/` (OTA-173: a crawler following season links would import every season; a test checks it and that there is no bare `Disallow: /`). There is deliberately no `Disallow: /`: crawlers must be able to fetch pages to see the noindex. OTA-149 flips the constant at cutover; see `docs/deploy-vercel.md`.
- Info and legal pages (OTA-147, design `docs/design/info/`): `/faq` is a static server page (native `<details name="faq">`, entries in `app/faq/faq-entries.tsx`; `faq-deep-link.tsx` is the only client code, opening `#q1`–`#q5`). `/privacy`, `/terms`, `/data-sources` render one `LegalPage` (`src/legal/legal-page.tsx`) from a typed `LegalDocument` per page (`src/legal/*.tsx`): section ids are the anchors (unique, tested), tables go through `LegalTable` (caption, `scope`, `data-label` cards on phones), reading time from `readingMinutes()`. Styles in `app/styles/info.css`. Change `lastUpdated` with any change that matters to readers; credit a source only while it is in use (AniList, MyAnimeList through Jikan, AnimeThemes; never "authorized by MyAnimeList" without MAL's written authorization, OTA-127); publisher, host, regions and retention are Farouk's confirmed facts (docs/progress/OTA-147.md), so change them only with him; a new cookie goes in the privacy cookie table. Until `/contact` ships, contact links use `CONTACT_HREF` (mailto) from `src/shell/site-footer.tsx`.
- Home (OTA-136, design `docs/design/home/`): `app/page.tsx` is a static hero (the h1 is the LCP element) then `HOME_ROWS` (`src/home/home-rows.ts`: Trending now = `airing`, This season = `seasonal`, Top rated = `top`). Each `HomeRow` (`app/home-row.tsx`) prerenders its head and streams its cards behind its own `Suspense` from `loadAnimeList()` (uncached, `?limit=12`, `isAnimeListPage`); `toHomeRowState()` dedupes by AniList id and caps at 8, and a failed row shows an inline alert while the others render. Card links are never prefetched (`prefetch={false}`) and a card without a slug links `/anime/anilist/:id` with `rel="nofollow"`. `.hm-row-slot` reserves the row height (356 px, 316 px on phones) so nothing shifts. The rows replace the old health status as the proof that `/` stays Partial Prerender (ADR 0003). Row styles in `app/styles/browse.css` (`.br-`), page styles in `app/styles/home.css` (`.hm-`).
- React review checklist (OTA-185): applies to every `apps/web` diff; whoever writes it follows it, `code-reviewer` checks it item by item on new or changed lines. ESLint (`core-web-vitals`) already catches some hook and key mistakes; look for what lint cannot see.
  - `useEffect` used to copy or compute data → compute during render (or `useMemo` if measured).
  - Server data fetched in the browser (`useEffect`, client `fetch`) → Server Component; no browser fetching until the client-data ADR (OTA-184) lands, then its query hooks (ADR 0003).
  - Hooks inside conditions, loops or after an early return → move them to the top level.
  - One big component with many boolean/config props → composition (small components as children).
  - State kept higher than needed → smallest useful scope (component, flow, page).
  - Styling outside the system: raw colours instead of tokens; raw px for spacing or radius where a `--space-*`/`--radius-*` token exists (font sizes, 1–2 px borders and outlines, fixed control heights and media queries stay px); inline styles for layout.
  - Stylesheets: new rules in `globals.css`, or unprefixed or bare-element selectors → a feature stylesheet with its own class prefix (`.ov-`, `.in-`, `.sh-`), as existing pages do.
  - New physical CSS properties (`margin-left`) where a logical one works (`margin-inline-start`); `left: 50%` paired with `translateX` stays physical.
  - List `key` from the index or `Math.random()` on a list that can reorder or filter → key from a domain id.
  - Animating anything but `transform`/`opacity` → change it (exceptions in "Motion and glass" above and ADR 0011).
